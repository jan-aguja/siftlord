# Sift Lord

Search Lazada and Shopee at once, without the popups, minigames and video ads. Results come back
as one clean list (one card at a time, or a compact list), ads hidden, sortable by price or sales.
Tap a result to open it in the store's own app.

Searches run on your phone in hidden browser views, as you. There's no server and no store API.
If a store wants you signed in, you sign in on its own page inside the app.

You can queue several searches; each fills in per store as it finishes.

## Run

```
flutter pub get
flutter run
```
